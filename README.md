# DevChat

**Windows-приложение для агентной разработки с ИИ через веб-интерфейсы — бесплатно, без API-ключей.**

DevChat превращает бесплатный веб-чат (DeepSeek, ChatGPT) в полноценную среду разработки: модель читает и пишет файлы, запускает команды, тестирует код — всё через ваш браузер, без оплаты API-токенов.

## Возможности

### Три режима работы

| Режим | Описание |
|---|---|
| **💬 Чат** | Обычный диалог с моделью (DeepSeek / ChatGPT) |
| **🔧 Агент** | Автономный агент: читает, пишет, запускает файлы и команды |
| **🤝 Команда** | Бригада специалистов: тимлид + UX + Backend + Frontend + Design + QA |

### Команда специалистов

Каждый специалист — отдельный ИИ-агент со своим контекстом, правилами и правами:

- **👤 Тимлид** — разбирает задачу, составляет план, назначает исполнителей
- **🎨 UX-дизайнер** — пользовательские сценарии, прототипы (только чтение)
- **⚙️ Backend** — данные, API, расчёты, серверная логика
- **⚛️ Frontend** — клиентский код, интерфейс
- **🖌 Web-дизайнер** — CSS, вёрстка, адаптивность
- **🧪 QA** — тестирование, проверка сценариев (без записи основного кода)
- **🔍 Ревьюер** — проверка изменений, вердикт ОК/замечания

### Управление агентами

- Создание, редактирование, удаление агентов через UI
- Импорт/экспорт файлов скиллов (`.md`)
- Включение/выключение агентов из состава команды
- Настраиваемые права: `full` / `readonly` / `run`
- Формат ответа: строгий протокол `<action>` + `<final>`

### Безопасность

- Песочница: все операции с файлами — только в пределах рабочей папки
- Подтверждения: все / только команды / отключены
- Диффы перед записью (что удалено, что добавлено)
- Журнал отката: возврат всех файлов к состоянию до изменений агента
- Лимиты: чтение 50 КБ, команды 60с, поиск 50 совпадений

### Устойчивость

- Автоматические повторные попытки при ошибках (таймауты, обрывы, лимиты)
- Ротация контекста: автоматический перенос в новый чат при переполнении
- Прогресс сохраняется в SQLite: «продолжить» после любого сбоя
- Переподключение расширения при потере связи
- Детект лимитов с временем сброса

### Интерфейс

- Тёмная тема (в духе VS Code / ZCode)
- Чеклист плана с зелёными галочками по мере выполнения
- Тайминги всех действий, этапов и общего прогона
- Живой индикатор хода: «⏳ Отправка → ⏳ думает → ✍ Отвечает»
- Сворачиваемая панель (план / файлы)
- Копирование и возврат сообщений в поле ввода
- Умный автоскролл (не мешает чтению)
- Метаданные: дата, автор, длительность каждого ответа
- Официальные брендовые иконки DeepSeek и ChatGPT
- Проверка обновлений с GitHub

### Компоненты

| Путь | Назначение |
|---|---|
| `src/App` | WPF-приложение (UI, агентное ядро, инструменты) |
| `src/Core` | WebSocket-сервер моста |
| `src/Cli` | Консольная утилита (REPL, e2e-тесты, диагностика) |
| `src/extension` | Chrome MV3-расширение (TypeScript + playwright-crx) |

### Стек

- **C# / .NET 8** — WPF, MVVM (CommunityToolkit.Mvvm)
- **TypeScript** — Chrome Extension (MV3, playwright-crx)
- **SQLite** (Microsoft.Data.Sqlite) — история чатов, журнал отката, состояние задач
- **esbuild** — сборка расширения

### Протокол взаимодействия

## Установка

### Требования

- Windows 10/11 (64-bit)
- Google Chrome
- Аккаунт DeepSeek (бесплатный) и/или ChatGPT

### Установка (инсталятор)

1. Скачайте `DevChat-Setup-x.x.x.exe` из [Releases](https://github.com/bmcoder/DevChat/releases)
2. Запустите инсталятор
3. При первом запуске нажмите кнопку **подключения** в шапке — установите расширение в Chrome (один раз, ~30 секунд)
4. Войдите в DeepSeek/ChatGPT в открывшемся Chrome
5. Зелёная точка = готово к работе

### Сборка из исходников

```bash
git clone https://github.com/bmcoder/DevChat.git
cd DevChat

# Chrome-расширение
cd src/extension
npm install
npm run build

# Приложение
cd ../..
dotnet build

# Запуск
dotnet run --project src/App
```

### Загрузка расширения вручную

1. `chrome://extensions` → включите «Режим разработчика»
2. «Загрузить распакованное расширение» → выберите `src/extension/dist`
3. Убедитесь, что расширение **DevChat Bridge** включено

## Использование

### Быстрый старт

1. Создайте чат (**＋ Новый чат**)
2. Выберите режим (**💬 / 🔧 / 🤝**)
3. Выберите провайдера (**🤖 DeepSeek / 🧠 ChatGPT**)
4. Опишите задачу — нажмите Enter

### Агентный режим (🔧)

Укажите рабочую папку в настройках (⚙). Агент сможет:
- Читать файлы (`read_file`)
- Создавать и изменять файлы (`write_file`) — с диффом и подтверждением
- Запускать команды (`run`) — с подтверждением
- Искать по коду (`search`)

### Командный режим (🤝)

1. Настройте состав команды (кнопка «Агенты» в шапке)
2. Опишите задачу — тимлид составит план
3. Каждый специалист выполнит свои пункты
4. QA протестирует, ревьюер проверит
5. Если есть замечания — разработчик исправит

### Подтверждения

| Режим | Поведение |
|---|---|
| 🔐 Все | Каждая запись и команда — через диалог с диффом |
| ⚙ Только команды | Файлы свободно, команды — через подтверждение |
| 🔓 Отключены | Полная автономия (песочница и откат работают) |

### Управление агентами

Кнопка **Агенты** (🤖) открывает редактор:
- Создание агентов с настраиваемыми правами
- Редактирование скиллов (правила, формат вывода)
- Включение/выключение из состава команды
- Импорт готовых файлов `.md`

Скиллы хранятся в `%AppData%\DevChat\skills\*.md`.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Enter` | Отправить сообщение |
| `Shift+Enter` | Новая строка |

### Лог и диагностика

- Полный журнал: `%AppData%\DevChat\log.txt`
- Кнопка **🩺 Диагностика** проверяет мост, вход, селекторы
- Консольная утилита: `dotnet run --project src/Cli -- auto`

## Структура данных

```
%AppData%\DevChat\
├── settings.json      # настройки (порт, токен, папка, провайдер)
├── devchat.db         # SQLite: чаты, сообщения, версии файлов, состояние задач
├── log.txt            # полный журнал работы
└── skills\            # скиллы агентов (markdown)
```

## Ограничения

- Автоматизация веб-чата может нарушать ToS провайдеров
- Селекторы DeepSeek/ChatGPT меняются при обновлениях интерфейса
- Один запрос за раз на провайдера (последовательная обработка)
- Лимиты бесплатных тарифов применяются
